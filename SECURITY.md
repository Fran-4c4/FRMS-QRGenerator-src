# Security policy

## Supported versions

Security fixes are applied to the current `main` branch. No binary release is
supported until a release is published from the public repository.

## Reporting a vulnerability

Use the repository's private security-advisory channel. Do not open a public
issue containing an exploit, personal information, credentials or a payload
derived from a real user.

QR payloads are processed locally. See [the security design](docs/security.md)
for trust boundaries and current limitations.
