# Changelog

All notable changes to this project are documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-21

### Added

- .NET 10 Windows Forms application with QR preview.
- Save As and clipboard workflows.
- Error-correction, module-size and color options.
- Friendly validation for empty, invalid and oversized payloads.
- Automated tests, locked dependencies and package vulnerability checks.
- Self-contained Windows publishing script.
- Open-source documentation, MIT license, application icon and continuous
  integration workflow.
